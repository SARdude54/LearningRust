## Common Rust Commands

| Command | Description |
|---|---|
| `cargo build` | Compile the project |
| `cargo run` | Build and execute |
| `cargo check` | Check code without generating the final executable |
| `cargo test` | Run automated tests |
| `cargo fmt` | Format Rust source code |
| `cargo clippy` | Analyze code for common mistakes |
| `cargo build --release` | Create an optimized build |
| `cargo clean` | Remove generated build artifacts |
